## 1. 제품 재정의 (피벗)

### 이전 포지셔닝 (기각)

~~"Framework-free React CRUD UI engine" — react-admin/Refine과 같은 범용 어드민 프레임워크 시장의 대안~~
→ 기각 사유: 생태계·신뢰 격차는 코드로 못 따라잡음. "framework-free" 표방 자체가 현실(순정 Node 로드 불가, 필수 UI peer 7종)과 배치되어 신뢰를 깎는 중.
> **오독 주의**: 기각 대상은 장기 목표가 아니라 **진입 수순**이다 — 아래 "이 피벗의 의미" 절 참조. 범용 시장은 포기가 아니라 교두보 이후의 확장 대상이다.

### 새 포지셔닝

> **"엔티티 선언 하나로 끝나는 CRUD 프론트엔드 엔진"** — 다음 세 시장의 교집합을 정조준한다:
>
> 1. **RCM-framework 수직 통합** (1순위): rcm-backend-framework 백엔드를 쓰는 팀의 공식 프론트 엔진. 백엔드 관례 지원은 "숨은 결합"이 아니라 `./backend/rcm` 어댑터로 **문서화된 1급 기능**.
> 2. **한국형 어드민** (2순위): 카카오맵·다음우편번호·한국 주소/전화 체계 내장 필드를 격리된 프리셋으로 제공하는, 한국 시장에서 가장 마찰 없는 CRUD 엔진.
> 3. **딥 서브컬렉션 니치** (3순위): 중첩 컬렉션 인라인 편집 + 리비전 히스토리 + 엑셀 왕복이 **무료로 전부 내장** — react-admin이 유료 EE로 파는 조합의 오픈소스 대안.

### 이 피벗의 의미 — 목표 하향이 아니라 진입 순서 (2026-07-10 사용자 논의 반영)

**장기 목표는 변하지 않는다: 범용 상용 CRUD 엔진.** 위에서 "기각"한 것은 목표가 아니라 첫 수 — 신뢰 계층(로드 가능성·semver·문서 정합)이 깨진 상태로 범용 시장의 신뢰 경쟁에 먼저 뛰어드는 것이다. 니치 3개는 도달 범위의 상한이 아니라 **교두보(beachhead)**다: 결과물 우위(선언 1회 = 리스트+폼+서브컬렉션+리비전+엑셀 완결)가 만든 본인이 아닌 **제3자에게 재현 가능함**을 가장 빨리 증명할 수 있는 곳에서 이기고, 그 실적 위에서 범용 시장으로 확장한다. react-admin 자신이 이 경로의 증거다 — marmelab의 내부 REST 어드민 도구(admin-on-rest)에서 출발해 범용 리더가 됐다.

로드맵 산출물(ADR-0001 패키징, ADR-0004 표면 동결·ui-default, ADR-0005 어댑터 계약·generic REST 레퍼런스)은 전부 니치 전용이 아니라 **범용 시장의 전제 조건이기도 하다** — 교두보에서 만드는 것이 곧 범용 진출 장비다.

**범용 확장 트리거** — 하나라도 충족되면 포지셔닝 확대(범용 시장 정면 진출)를 재논의한다:

- 비RCM 백엔드 프로덕션 채택 ≥ 2건 (`backend/rest` 등 어댑터 경유, 포크/패치 없이)
- `ui-default` 서브패스 기준 quick-start 완주가 실측 30분 내로 단축·유지
- 커뮤니티발 기여(백엔드 어댑터 또는 필드 렌더러) ≥ 1건

### 수익 모델

**(A) OSS + 구축/지원 용역 × (C) 내부 플랫폼 표준** 하이브리드. 기존 무료 기능의 유료벽 후퇴는 금지(Do-NOT). 유료화 여지는 신규 부가 모듈(감사로그, 실시간 협업, AI 보조 입력)만.

## 3. v1.0 스코프

보존 대상 개념(선언=화면, 정책=데이터, 관계 1급, 필드 카탈로그의 미시 결정 등 C1~C9)의 단일 명세는 [개념 헌장](./concept-charter.md)이다 — 아래 조건들과 별개로, 헌장의 어떤 개념도 재기초에서 탈락하면 안 된다.

### 반드시 (조건 C1~C4 — 미충족 시 v1 선언 불가)

- **C1 소비 가능성**: 순정 Node/주요 번들러/CJS·ESM에서 로드 성공. CI 로드 스모크. → ADR-0001
- **C2 표면 신뢰**: 공개 배럴 ~200 심볼 화이트리스트, 도메인 잔재 격리(`./presets/rcm`), @deprecated 유예 체계, semver 규율 명문화·준수. README의 모든 주장이 실측과 일치. → ADR-0004
- **C3 코어 성능/구조**: 폼 상태 인스턴스 store(키 입력 리렌더 범위 = 해당 필드), config↔render 계약 분리(순환 의존 213→목표 <20). → ADR-0002, ADR-0003
- **C4 보안/품질 기준선**: HtmlField sanitizer 계약, 권한 게이트 fail-open 제거, 렌더 테스트 인프라 + 커버리지 래칫, 환경 고정. → ADR-0006, ADR-0007

### 해야 함 (v1 가치 완성)

- BackendAdapter 계약 + `./backend/rcm` 기본 어댑터 + generic REST 레퍼런스 어댑터 (ADR-0005)
- `@rchemist/listgrid/ui-default` — 필수 peer를 코어에서 걷어낸 공식 스타일드 프리미티브 서브패스 (ADR-0004 §peer)
- i18n: 코어 사용자 표면(검색 연산자 24종·세션만료 모달·리스트/폼 공통 문구) 키 체계 이관
- `apps/sample` — 내장 샘플 사이트([명세](./sample-site-spec.md)): quick-start 검증 + alpha 데모 + 헌장 시연 + **확장성 증명 6종**(CSS 토큰/classNames/프리미티브 교체/커스텀 필드/자체 wrapper/어댑터 교체)
- 중복 정리: SubCollection 3변형·Xref 4형제·misc/utils 이중 API·FieldRenderer onChange 2벌 (~400-500줄)

### 하지 않음 (Non-goals — 기존 + 신규)

- 실시간 sync/WebSocket, optimistic UI/뮤테이션 큐, offline-first (기존 유지 — 호스트 데이터 레이어 책임)
- Vue/Svelte/Angular 포팅, 비주얼 폼 빌더, 차트/대시보드 (기존 유지)
- **(신규)** rewrite-from-scratch, SubViewEntityForm 단독 분리, xstate 단독 도입, 전역 싱글턴 Context화, 무료 기능 유료화 — 분석이 기각한 경로 (보고서 §7 Do-NOT)
- **(신규)** SSR 멀티테넌트 지원 — 판매 포인트로 확정하기 전까지 보류 (ADR-0003 §싱글턴, P2 이후 선택)

## 4. 릴리스 전략 (2026-07-10 ADR-0008로 개정 — 재기초 + 장기 이식)

실행 전략은 [ADR-0008](../adr/ADR-0008-refoundation-strategy.md)이 규정한다: 제자리 순차 재설계 대신 **v0.4 브랜치의 워크스페이스에 4계층 골격을 신축하고 검증된 로직을 이식**한다. 보존 대상 개념의 단일 명세는 [개념 헌장](./concept-charter.md)이며 0.4.0 GA 게이트에서 대조한다.

| 라인 | 브랜치 | 역할 |
|---|---|---|
| 0.2.x | release/0.2 | 유지보수 (기존 관례) |
| 0.3.x | main | 유지보수 — 버그픽스만, **BREAKING 금지**. P0 핫픽스 = 0.3.26 |
| **0.4.x** | **v0.4** | **재기초 엔진** — 개발 중 0.4.0-alpha.N(dist-tag `next`) 상시 배포, parity+헌장 대조 통과 시 GA. GA 시 main→release/0.3 이관 + v0.4 승격 |
| 1.0 | — | 새 기능이 아니라 **표면 동결 선언** — 0.4.x가 프로덕션에서 검증되고 아래 §5 기준 충족 시 승격 |

v1.0 선언 기준 (구 ROADMAP 기준을 갱신): `@deprecated` 0건 · 외부(비 원 호스트 계열) 프로덕션 채택 ≥1 · 커버리지 40%+(렌더 테스트 포함) · 로드 스모크 매트릭스 green · 공개 API semver freeze.

## 5. 성공 지표

- **온보딩**: 신규 Next.js 프로젝트에서 quick-start 완주(첫 리스트+폼 렌더)까지 **30분 이내** (examples/minimal로 측정)
- **성능**: 100필드 폼에서 키 입력당 리렌더 컴포넌트 수 = 상수(해당 필드 + 폼 루트 이하 고정 개수). 1,000행×20페이지 리스트 조작 60fps
- **신뢰**: README·CHANGELOG·패키지 실동작의 불일치 0건 (릴리스 게이트로 강제)
- **채택**: 6개월 내 비-GJCU 계열 신규 프로젝트 1건 이상이 포크/패치 없이 채택
